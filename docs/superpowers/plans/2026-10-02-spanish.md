# Spanish as a Third L1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spanish speakers (L1 `es`, Spain's Spanish) learn English in Wordado. This needs:
- a Spanish corpus pack;
- a Spanish demo sample;
- a Spanish interface;
- Spanish reminders and sign-in email;
- Spanish wherever the app lets a learner choose a native language.

**Architecture:**
- **Content.** Plans 9, 10 and 11 made a new L1 mostly content work. The pipeline gains a Spanish translation guide (`L1_GUIDES.es`). The content repository gains `es` in `pipeline.json` and Spanish theme names. A local draft on the product owner's Claude plan writes the Spanish translations and unit titles.
- **Code.** In the app, `es` joins `SUPPORTED_L1S` in core, the reminder languages on the server, and the interface tables in web. The setup, the Settings language page, `watchL1`, report triage and the L1-plus-English interface rule all follow `SUPPORTED_L1S` and need no change.

**Tech Stack:** pnpm monorepo, TypeScript 7 (`exactOptionalPropertyTypes`), Vitest, Playwright, Postgres migrations, Cloudflare Workers/R2, the corpus pipeline with `CORPUS_LLM=claude-code`.

**Spec:** `docs/superpowers/specs/2026-09-20-vocabulary-learning-app-design.md`. The relevant sections:

## Decisions

1. **Spain's Spanish (`es-ES`).**
   - Translations and the interface use the vocabulary of Spain: ordenador, coche, móvil, zumo, patata, conducir.
   - Spelling is standard, with accents, ñ, and opening ¿ and ¡.
   - The language code stays `es`, matching `bg` and `de`.
2. **The interface uses the informal "tú"**, as the German interface uses "du". The informal plural ("vosotros") is used where a plural address is needed.
3. **Spanish goes out unreviewed**, like Bulgarian and German v1 (`accept_unreviewed` gains `translation-es` and `title-es`). A native review comes later.
4. **The draft runs on the product owner's Claude plan** (`CORPUS_LLM=claude-code`), as German did. That run cost about $17 API-equivalent; it was not billed.
   - It asks only Spanish: the Bulgarian and German caches answer their own questions.
   - Task 6 checks that the Bulgarian and German packs come out unchanged.
5. **Release order, as plan 10 set it.** Release v3 (adding `corpus-es`) goes out before the app's pull request is merged. Old builds pick packs by L1, so they ignore it.
6. **Theme names and the demo sample are written by hand.** That covers the 43 content themes' Spanish names and descriptions, and the sample's 60 words, 3 unit titles and 24 theme names. They are short, and the theme names are part of the themes question.

### Task 1: pipeline — the Spanish translation guide

**Files:**
- Modify: `pipeline/src/stages/translate.ts` (`L1_GUIDES`)

- [ ] **Step 1: Write the failing tests**
  - `L1_GUIDES` has an `es` entry, and it names Spanish as written in Spain.
  - A translate request for `es` carries the Spanish guide in its system prompt. Use the file's existing pattern for `de`.
  - If `titles.ts` maps L1 codes to language names, a title request for `es` names Spanish.
- [ ] **Step 2: Run them and see them fail.** Run: `cd pipeline && npx vitest run src/stages`. Expected: FAIL.
- [ ] **Step 3: Implement.** Add this guide:

```ts
  es: `Translate into Spanish, as a bilingual dictionary would.
- Nouns: the singular, without the article (agua, not el agua): the learners are Spanish speakers and know the gender.
- Verbs: the infinitive (escribir). Pronominal verbs as a dictionary gives them (llamarse; acordarse).
- Adjectives: the masculine singular (grande, rojo).
- Interjections and phrases: what a Spanish speaker in Spain would actually say, with ¿ and ¡ where the phrase is a question or an exclamation.
- Alternates: other translations a learner might give that are also correct for this sense, most common first, at most four. No near-synonyms that would be wrong in the example sentence.
- Sense: two to four Spanish words that tell this sense apart from the headword's other senses (for bank: "entidad financiera", "orilla del río"). Empty when the gloss is empty.
Use the standard Spanish of Spain (ordenador, coche, móvil, zumo, patata), with accents and ñ. No English words, no explanations in brackets.`,
```

- [ ] **Step 4: Run and see them pass.** Run: `cd pipeline && npx vitest run && cd .. && pnpm typecheck && pnpm lint`. Expected: PASS.
- [ ] **Step 5: Commit.** Subject: `feat(pipeline): a Spanish translation guide`.

    - The informal "tú" throughout (Decision 2). Imperatives in the "tú" form: "Elige", "Empieza", "Descarga".
