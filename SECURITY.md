# Security

If you find a security problem in Wordado (the app, its server or the review app), please do not open a public
issue. Write to **hello@wordado.com** with what you found and how to reproduce it.

Every report is read. Please give us time to fix the problem before you publish it.

Only the version that is live at [app.wordado.com](https://app.wordado.com), built from the `main` branch, is supported.
